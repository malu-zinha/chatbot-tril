🔐 CONFIGURAÇÃO DO SUPABASE (VOCÊ PRECISA FAZER)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❌ 1. Obter credenciais do Supabase
     → Acesse: https://app.supabase.com
     → Settings → API
     → Copie: Project URL e anon public key

❌ 2. Configurar .env.local
     → Abra: dashboard/.env.local
     → Cole as credenciais
     → Salve o arquivo
     → Reinicie o servidor

❌ 3. Executar scripts SQL no Supabase (SQL Editor)
     Script 1: supabase/MASTER_SCHEMA_COMPLETO.sql
     Script 2: supabase/views_dashboard_blocos.sql
     Script 3: supabase/tabela_evandro_dono.sql
     Script 4: supabase/functions_dono.sql
     Script 5: supabase/security_policies.sql (opcional)

❌ 4. Habilitar Realtime
     → Database → Replication
     → Habilite: engenheiros_projetos, projetos_previsao, retrabalho_projetos

⚠️  5. Inserir dados de teste (opcional)
     → Se banco vazio, execute queries de teste
     → Ver: STATUS_DEPLOY.md seção 4
