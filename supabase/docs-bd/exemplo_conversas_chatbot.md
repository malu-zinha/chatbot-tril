## 🎯 Comandos Rápidos

Os engenheiros podem usar atalhos:

**📋 Comandos disponíveis:**

- `meus projetos` → Lista projetos ativos
- `status` → Status geral
- `ajuda` → Menu de ajuda
- `áreas` → Lista áreas disponíveis
- `criar [código] [cliente]` → Cria projeto
- `atualizar [projeto]` → Atualiza status
- `concluir [projeto]` → Marca como concluído
- `histórico` → Últimas interações

**Exemplos:**

```
👤: meus projetos
🤖: [lista os projetos]

👤: status
🤖: [mostra resumo geral]

👤: criar PRJ-999 ClienteABC
🤖: [cria o projeto]

👤: atualizar PRJ-999
🤖: [inicia fluxo de atualização]
```

## 💡 Dicas de Uso

### ✅ Boas Práticas

1. **Seja natural:** O chatbot entende linguagem comum
   - ✅ "Terminei o elétrico"
   - ✅ "O projeto atrasou 3 dias"
   - ✅ "Mudei para fase de acabamento"

2. **Atualize diariamente:** Mantenha o sistema sempre atualizado

3. **Registre retrabalhos:** Importante para métricas e melhorias

4. **Use atalhos:** Comandos rápidos economizam tempo

5. **Seja específico:** Quanto mais informação, melhor
   - ❌ "Atualizei"
   - ✅ "Atualizei o elétrico do PRJ-001 para instalações"

### ⚠️ O que evitar

1. ❌ Múltiplas atualizações conflitantes ao mesmo tempo
2. ❌ Siglas ou códigos não cadastrados
3. ❌ Datas ambíguas ("semana que vem" → use "15/12")
